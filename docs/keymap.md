# Keymap

`DESIGN.md` §7.4 と同期する、非モーダルの固定キーマップです。

## Editor

| Key | Action |
| --- | --- |
| 印字キー | 全カーソルへ文字挿入 |
| `Enter` / `Backspace` / `Delete` | 改行 / 前削除 / 後削除。Backspaceは直前の設定幅space、または空の自動補完ペアをまとめて削除 |
| 矢印 / `Home` / `End` | カーソル移動 |
| `Ctrl+←/→` | 単語移動 |
| `Ctrl+Home` / `Ctrl+End` | 文書先頭 / 末尾へ移動 |
| `Shift+移動` | 選択拡張 |
| `Ctrl+A` | 全選択 |
| `Ctrl+D` | 次の同一語を選択 |
| `Ctrl+Alt+↑/↓` | 上下にカーソル追加 |
| `Tab` / `Shift+Tab` | 選択なしは設定幅を挿入、範囲選択時は対象行をインデント / アンインデント |
| `Ctrl+/` / `Ctrl+Q` | コメントトグル |
| `Ctrl+Z` / `Ctrl+Y` | undo / redo |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | コピー / カット / 貼り付け。選択なしのコピー・カットは現在行 |
| `Ctrl+S` | 保存 |
| `Ctrl+W` | バッファを閉じる |
| `Ctrl+T` | ファイルピッカー。再押下で閉じる |
| `Ctrl+P` | コマンドパレット。コマンド名・説明・キーバインドを検索し、`Enter`で実行 |
| `Ctrl+G` | 開いているバッファのピッカー。再押下で閉じる |
| `F6` | 比較対象バッファを選び、現在のバッファを左、対象を右に diff 表示 |
| `Ctrl+F` / `Ctrl+H` | 検索 / 置換。再押下でスコープ循環 |
| `Ctrl+Shift+F` | ディレクトリ検索 |
| `Ctrl+@` / `Ctrl+Space` | 補完ポップアップ切替 |
| `F2` | LSP リネーム |
| `Ctrl+]` | 左右エディタ分割切替 |
| `Ctrl+O` | シェル表示切替（非表示でもセッションは継続） |
| `Esc` | オーバーレイを閉じる / primary 選択へ単一化 |
| `F4` | 終了 |

## Mouse

| Action | Result |
| --- | --- |
| クリック | フォーカスとカーソルを移動 |
| ドラッグ | 範囲選択 |
| ダブルクリック | 単語選択 |
| トリプルクリック | 行選択 |
| ホイール | スクロール |
| `Alt+クリック` | カーソル追加 |
| `Ctrl+クリック` | LSP 定義ジャンプ |

## Overlay

| Key | Action |
| --- | --- |
| 印字キー | クエリ入力 |
| `↑` / `↓` | 候補選択 |
| `Enter` | 確定 |
| `Backspace` | 1文字削除 |
| `Esc` | 閉じる |
| `Tab` | 置換・include・exclude入力欄を移動 |
| `Alt+C` / `Alt+W` / `Alt+R` | 大文字小文字 / 単語単位 / 正規表現を切替 |
| `Alt+I` / `Alt+V` | ignoreファイル尊重 / hiddenファイル対象を切替 |

ピッカー表示中は、ピッカー外の左クリックでも閉じます。

補完表示中は`↑`/`↓`、`Enter`、`Ctrl+C`、`Esc`、`Ctrl+@`だけが候補操作です。それ以外は通常のEditor操作として実行されます。
検索・置換ペインでは`Ctrl+C`で閉じません。`Esc`で閉じます。

## Shell

シェル固有入力はPTYへ転送し、`Ctrl+O`などのグローバルキーだけをエディタが処理します。
シェルペインは左ドラッグで文字選択し、マウスを離すとOSC52で端末側クリップボードへコピーします。選択中の`Ctrl+C`もコピーとして扱い、未選択時はSIGINTです。
シェルペイン上のホイールは10,000行のスクロールバックを移動します。
